# Orthopédie Avicenne

Site de présentation du service de chirurgie orthopédique et traumatologique de l’Hôpital Avicenne AP-HP.

## Prévisualisation locale

Le site est statique. Lancez un serveur local à la racine du projet :

```bash
python3 -m http.server 4173
```

Puis ouvrez `http://localhost:4173`.

## Structure

- `index.html` — contenu et structure de la page
- `styles.css` — direction artistique et responsive
- `script.js` — navigation mobile, animations et interactions
- `assets/` — photographies et ressources visuelles

## Sources éditoriales

Les informations médicales et pratiques sont issues des pages officielles de l’AP-HP, liées depuis le site. Les photographies institutionnelles sont créditées AP-HP dans la page.
